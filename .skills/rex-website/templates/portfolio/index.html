01 / About

Defence first. Offence to prove it.

REX is a security practice built around one rule: a control is only as good as the evidence that it works. Attack paths are reproduced in a lab, mapped to MITRE ATT&CK, and turned into detections that are tested before they are shipped.

Write-ups stay technical. They name the tooling, show the telemetry and state the limits of each result.
