# Layout, spacing and graphic motifs

## Grid and spacing

- 12-column grid: `.grid-12` with `.col-3/4/5/6/7/12`. Container max 76rem (1216px) content plus `--page-pad` (20-48px).
- Gutter 16-32px fluid (`--gutter`). Breakpoints: 1080px (3/4-col items become halves, 5/7 stack), 680px (everything full width).
- Typical splits: 5/7 (heading + content), 7/5 (text + panel), 4/4/4 (cards), 3x4 (four services). Hero copy spans 8 columns, art fills the rest.
- Spacing scale on 4px: 4, 8, 12, 16, 24, 32, 48, 64, 96, 128. Section padding 72-144px (`--section-pad`). Be generous: one idea per section, lots of obsidian.
- Left-aligned text. Centre only short single lines (rarely).
- Sharp geometry: radius 2px max. No pill shapes, no soft drop shadows. Depth comes from surfaces, borders, indigo glows in art.

## Primary motif: diagonal cuts

- Section dividers use `clip-path`, all at the same angle: top edge rises left to right, bottom edge rises left to right.
  ```css
  .section--cut { padding-block: calc(var(--section-pad) * .8 + var(--cut));
    clip-path: polygon(0 var(--cut), 100% 0, 100% calc(100% - var(--cut)), 0 100%);
    margin-block: calc(var(--cut) * -0.5); }
  .hero { clip-path: polygon(0 0, 100% 0, 100% calc(100% - var(--cut)), 0 100%); }
  ```
- `--cut` is clamp(2rem, 5vw, 5.5rem). Pad content by the cut so nothing is clipped.
- Optional 2px gradient hairline on the top cut (`.section--cut::before`). At most one hairline per cut.
- Alternate: cut section (raised bg) / plain section. Do not cut every section; 2-3 cuts per page is enough.
- Chamfered corners (angled frames) on cards, primary buttons and panels. Draw borders with the two-layer technique (element = border colour, `::before` inset 1px = fill, both clipped) so the chamfer edge keeps its border.

## Shape order and frequency (reference/visual-system-geometric-elements.webp)

| # | Shape | Frequency | Web use |
|---|---|---|---|
| 01 | Triangles | very frequent | hero/OG art, section accents |
| 02 | Slanted blocks | very frequent | hero art (template uses combination 02) |
| 03 | Dotted patterns | frequent | CSS dot grid on one raised section |
| 04 | Angles + grids | frequent | background of data/diagram sections |
| 05 | Angled frames | moderate | chamfered cards, contact frame |
| 06 | Layered panels | moderate | feature/case-study headers |
| 07 | Hexagons | additional | sparing, infra/network topics |
| 08 | Abstract 3D | occasional | one feature image max |
| 09 | Rhombus / diamond | rare | tiny functional nodes only (timeline dots) |
| 10 | Glitch | very rare | avoid on the site; maybe a 404 page |
| 11 | Gradient blobs | very rare | avoid; use the subtle gradient background instead |

Restraint rules:
- Max two motifs visible per viewport, one of them diagonal cuts. Not every motif in every design.
- One large brand graphic per page (the hero). Elsewhere use CSS-drawn motifs (dots, hairlines, chamfers).
- Blue-to-violet gradients only on obsidian or as thin rules; on light themes use the `-light` art variants.
- Art never sits under body text without a scrim; keep text on the obsidian/white side of the composition.

## Brand graphics

Generated by other agents; reference by path, never modify:
`asset/graphics/{shapes,backgrounds,combinations}/NN-name.svg|png` with a `-light` sibling for light themes, e.g.
`asset/graphics/combinations/02-diagonal-cuts-slanted-blocks.svg`, `.../01-diagonal-cuts-triangles.svg`, `.../03-dotted-patterns-grids.svg`, `.../05-layered-panels-frames.svg`.
The combination SVGs carry their own obsidian/white background and put the art on the right, so they work as `background: right center / cover` with a left-side scrim.
Use SVG, not the PNG exports, on the web (2-35 KB vs 300-700 KB). Copy them with `scripts/copy_assets.py --graphics combinations/NN-name`.
`backgrounds/` may not exist yet; check with Glob before referencing.
